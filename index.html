PACKAGE.JSON SETUP

Add FIXO-BAILEYS to your package.json

Prefer managing dependencies manually? Add the package directly to your package.json file instead of running the install command.

Open your project's package.json, find the dependencies object, and add fixo-baileys in this exact format:

{
  "name": "my-whatsapp-bot",
  "version": "1.0.0",
  "main": "index.js",
  "type": "module",
  "dependencies": {
    "fixo-baileys": "^1.0.1",
    "pino": "^9.0.0"
  }
}
FieldValueMeaning
"fixo-baileys""^1.0.1"Package name and version range
^Caret prefixAuto-updates to any 1.x.x release (safe minor & patch updates)
"type""module"Required if you use ESM import syntax
⚠️ Important: Each line inside dependencies except the last must end with a comma. Missing commas are the #1 cause of JSON parse errors.
AFTER EDITING

Install from your updated package.json

Once the entry is saved, run the install command — your package manager reads package.json and pulls the exact version listed.

npm
yarn
pnpm
npm install
Version RangeBehaviour
"^1.0.1"✅ Recommended — accepts 1.0.1 up to <2.0.0
"~1.0.1"Accepts patch updates only (1.0.x)
"1.0.1"Locks to that exact version
"*"⚠️ Not recommended — any version, may break
IMPORT IT

Use it in your code

Once installed, import it just like the original Baileys package.

import makeWASocket, { useMultiFileAuthState, DisconnectReason } from 'fixo-baileys'
💡 Tip: Always run your install command after editing package.json so the new dependency is downloaded into node_modules. Commit package.json and package-lock.json together for reproducible builds.
QUICK CONNECT

Scan a QR code and you're live

import makeWASocket, { useMultiFileAuthState } from 'fixo-baileys'
import P from 'pino'

async function bootUp() {
  const { state, saveCreds } = await useMultiFileAuthState('fixo_session')

  const sock = makeWASocket({
    auth: state,
    logger: P({ level: 'silent' }),
    printQRInTerminal: true,
    browser: ['FIXO-BAILEYS', 'Chrome', '1.0.0']
  })

  sock.ev.on('creds.update', saveCreds)
  sock.ev.on('connection.update', ({ connection }) => {
    if (connection === 'open') console.log('FIXO-BAILEYS is live!')
  })
}

bootUp()

RESILIENCE

Auto-reconnect with backoff

sock.ev.on('connection.update', ({ connection, lastDisconnect }) => {
  if (connection === 'close') {
    const code  = lastDisconnect?.error?.output?.statusCode
    const retry = code !== DisconnectReason.loggedOut
    if (retry) setTimeout(resilientConnect, 3000)
  }
})
