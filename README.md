## 🎀 Wʜᴀᴛ ɪꜱ FIXO-BAILEYS? 🎀

</div>

> ⚡ **FIXO-BAILEYS** is a **completely rebuilt, privacy-first fork** of the Baileys WhatsApp Web API — engineered from the ground up by **FIXO DEV** to deliver unmatched performance, ironclad privacy, and a buttery-smooth developer experience.

We stripped the original Baileys engine down to its core, **removed every hidden tracker**, **killed every background telemetry endpoint**, and **eliminated all the auto-follow newsletter junk**. What remains is a lean, mean, **pure messaging machine** 💫

<div align="center">

> [!IMPORTANT]
> 💖 **Drop-in replacement.** Every original Baileys API works identically. Zero rewriting. Zero breaking changes. Just a pure upgrade.

</div>

**🔑 Key Highlights:**

- 🌐 **WhatsApp Web API** — Full Multi-Device support
- 🔐 **Signal Protocol** — End-to-end encryption out of the box
- 📦 **2GB Streaming** — Push large media without RAM blowups
- 🚀 **Zero Telemetry** — No trackers, no analytics, no phone-home
- 🎨 **Rich Messaging** — Buttons, lists, templates, reactions
- ⚡ **Async/Await Native** — Modern JavaScript / TypeScript ready

<details>
<summary><b>🔄 Route 3 — Auto-Reconnect Powerhouse 🌷</b></summary>

<br/>

```javascript
import makeWASocket, {
    useMultiFileAuthState,
    DisconnectReason,
    fetchLatestBaileysVersion
} from 'fixo-baileys'
import { Boom } from '@hapi/boom'
import P from 'pino'

async function resilientConnect() {
    const { state, saveCreds } = await useMultiFileAuthState('fixo_session')
    const { version } = await fetchLatestBaileysVersion()

    const sock = makeWASocket({
        version,
        auth: state,
        logger: P({ level: 'silent' }),
        printQRInTerminal: true,
        browser: ['FIXO-BAILEYS', 'Chrome', '1.0.0'],
        defaultQueryTimeoutMs: 120_000,
        connectTimeoutMs: 60_000,
        enableAutoSessionRecreation: true,
        markOnlineOnConnect: false,
        syncFullHistory: false,
    })

    sock.ev.on('connection.update', ({ connection, lastDisconnect }) => {
        if (connection === 'close') {
            const code  = (lastDisconnect?.error as Boom)?.output?.statusCode
            const retry = code !== DisconnectReason.loggedOut

            console.log(`💔 Disconnected — Code: ${code}`)

            if (retry) setTimeout(resilientConnect, 3_000)
            else       console.log('🚪 Logged out — rescan needed.')
        } else if (connection === 'open') {
            console.log('💖 FIXO-BAILEYS online!')
        }
    })

    sock.ev.on('creds.update', saveCreds)
    return sock
}

resilientConnect()
```

sock.ev.on('messages.upsert', async ({ messages }) => {
    const m = messages[0]
    if (!m.message) return

    // 💖 Button response
    const btn = m.message?.buttonsResponseMessage
    if (btn) {
        const id  = btn.selectedButtonId
        const replies = {
            go_yes: '✅ You said YES!',
            go_no:  '❌ You said NO!',
            go_hmm: '🤔 Maybe...'
        }
        if (replies[id]) {
            await sock.sendMessage(m.key.remoteJid, { text: replies[id] })
        }
    }

    // 🌸 List response
    const list = m.message?.listResponseMessage
    if (list) {
        const row = list.singleSelectReply?.selectedRowId
        if (row === 'u_profile') {
            await sock.sendMessage(m.key.remoteJid, {
                text: '👤 *Your Profile*\nName: FIXO User 💖'
            })
        }
    }
})
